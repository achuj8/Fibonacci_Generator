# Fibonacci Generator

## 📖 Overview
This is a simple Python program that generates the Fibonacci series based on user input. 

The Fibonacci series is a sequence of numbers where each number is the sum of the two precending numbers. This project is created as a beginer-friendly to understand basic programming concepts such as loops, variables, and user input.

---

## 🙄 What is the Fibonacci Series??
The Fibonacci series starts with:

    0, 1

Each next number is calculated as:

    F(n) = F(n-1) + F(n-2)

### 📚 Example:

    0, 1, 1, 2, 3, 5, 8, 13, ...
